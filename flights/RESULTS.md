## 다시 실행하기

```bash
pip install -r requirements.txt
mkdir -p out
python crawl.py SEL TYO 2027-01-01 2027-02-28
python crawl.py TYO SEL 2027-01-03 2027-03-07
python analyze.py        # 조합 계산 → out/combos.json
python verify_rt.py 20   # 상위 20개 왕복 실검색 검증

python verify_rt_time.py 20
```
