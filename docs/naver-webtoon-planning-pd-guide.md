# 네이버웹툰 기획/PD 직군 합격 후기 정리 & 준비 가이드

> 대상: **기획 / 콘텐츠 PD / 사업 직군**, **재학 중인 학생**
> 조사일: 2026-09-08
> 출처: 네이버웹툰 공식 채용사이트(네웹취뽀썰), 링커리어 커뮤니티 합격후기, 잡플래닛 면접후기(229건), 잡코리아 자소서 문항, 자소설닷컴 공고 아카이브
> ⚠️ 원문 페이지 직접 접근이 제한된 환경에서 조사되어, 검색 결과 요약을 근거로 재구성했습니다. 지원 전 원문 확인 권장.

## 1. 전형 절차 (신입 / 채용연계형 인턴)

```
지원서 리뷰
  ↓
실무 인터뷰 (Pre Interview)   ← 20~30분, 캐주얼, 1:다
  ↓
인턴십 약 6주                 ← 멘토-멘티 배정 / 중간 과제 발표 → 최종 과제 발표
  ↓
Culture-Fit 인터뷰            ← 온라인 기업문화 적합도 검사 포함
  ↓
입사 (정규직 전환)
```

- 인턴십 중 **중간 과제 발표 → 최종 과제 발표**가 핵심 평가 지점. 소속 부서 리더·멘토 앞에서 발표.
- 인턴십 종료 시점까지의 누적 평가로 전환 면접 진행 여부가 갈림.
- 전환율에 대한 공식 수치는 공개되지 않음. 커뮤니티에서는 "높지 않다"는 평이 있으나 검증되지 않은 의견이며, 개인 성과·팀 T/O에 따라 편차가 큼.

## 2. 자기소개서 — 반복 출제되는 문항

기획/콘텐츠/서비스 직군 공고에서 반복적으로 확인되는 문항들:

| # | 문항 | 출제 의도 |
|---|------|-----------|
| 1 | 가장 좋아하는 콘텐츠(영화·소설·드라마·웹툰·게임 등)를 하나 골라 **매력적인 이유를 3가지 키워드로** 정리 | 취향 유무가 아니라 **분석을 압축하는 능력** |
| 2 | 평소 여가시간에 즐겨보는 콘텐츠 / 주로 체류하는 채널 | 실사용자로서의 밀도 |
| 3 | 최근 가장 재미있게 본 콘텐츠와, 그것이 **대중에게 인기 있는(혹은 없는) 이유** | 내 취향 ≠ 시장 반응을 분리해서 볼 수 있는가 |
| 4 | 네이버웹툰 서비스(웹툰 / 시리즈 / 시리즈온 / LINE WEBTOON) 중 하나를 골라 **이용 습관과 장단점** | 자사 서비스 실사용 + 개선 관점 |
| 5 | 미국에서 서비스 중인 콘텐츠 앱 중 최근 재미있다고 생각한 앱과 이유 | 글로벌 레퍼런스 감각 |
| 6 | 포트폴리오 중 **가장 자신 있는 프로젝트 1개** 소개 | 깊이 있는 한 방 |
| 7 | 지원 동기 + 입사 후 이루고 싶은 목표 | 일관성 |

**합격자들이 꼽은 자소서 승부처**
- 문항마다 **background(왜 이 소재를 골랐는지)** 와 **research(근거 데이터/사례)** 를 붙였다.
- 전체 문항을 관통하는 **"일관성 있는 이미지"** 를 설계했다. (문항별로 다른 사람처럼 보이면 감점)
- 웹툰 PD 직무 자체에 대한 이해가 완벽하지 않아도 합격 사례가 있음. 대신 **콘텐츠 산업 전반에 대한 인사이트**가 더 중요하게 작용.

## 3. 면접

**정량 지표 (잡플래닛, 후기 229건 기준)**
- 면접 난이도: **3.4 / 5**
- 면접 경험: 긍정 60% / 부정 8%
- 지원 경로: 온라인 지원 77%

**진행 방식 (콘텐츠기획·PD팀 사례)**
- 구성: 실무진 2명 + 소속 팀 리더 1명 + **타 팀 리더 1명**
- 분위기: 복장 자유, 캐주얼. 다만 **질문 자체는 날카로울 수 있음**
- PT 면접이 포함된 사례 있음 (이 경우 면접 시간이 짧은 편)

**질문 성향**
- 정형화된 질문보다 **경험 기반 질문**이 압도적으로 많음 — "이 지원자가 어떤 사람인지" 알아내려는 목적
- 인성 질문 + **"직무 수행 중의 마인드"를 검증하는 질문**
- 답변은 취준생이 아니라 **실제로 그 일을 하는 사람의 입장**에서 해야 함

**현직자가 권한 준비법**
> "네이버웹툰과 왜 함께 하고 싶은지, 인턴십 동안 어떤 일을 해보고 싶은지, 그 일을 하기 위해 어떤 역량을 갖췄는지를 보여줄 수 있는 **본인만의 경험**을 정리해보라."

## 4. 스펙에 대한 실제 증언

- **정형화된 스펙(학점·어학·자격증·인턴 횟수)은 중요하지 않다**는 것이 공식 후기와 커뮤니티 후기의 공통 진술.
- "스펙보다 **경험을 통해 어떤 생각과 가치관을 갖게 됐는지**"를 본다.
- 나이를 보지 않는 편 (다양한 연령대의 인턴이 함께함).
- 다만 **콘텐츠 / 기획 관련 경험**이 있으면 유리하다는 언급은 반복됨.

---

## 5. 포트폴리오 — 웹툰 PD 기준 (현직자 조언)

1. **웹툰 분석 + 기획서** 두 축으로 구성
2. 분석은 **장르 불문**으로 — 인기작 / 비인기작 / 신작을 섞어 **5~6개 작품 리뷰**
3. **웹소설을 원작으로 한 웹툰 기획**(노블코믹스)을 해보는 것이 실무와 가장 가까움
4. 업무에 늘 **"why"** 를 붙이는 태도 — 이 일이 왜 필요하고 어떤 점이 중요한가

## 6. 그래서 나에게 필요한 것 (재학생 / 기획·PD 지원 기준)

### A. 반드시 있어야 하는 것 (없으면 서류에서 걸림)

| 필요한 것 | 구체적으로 |
|---|---|
| **콘텐츠 분석 근육** | 작품 5~6편을 "재밌다"가 아니라 **왜 시장이 반응했는가**로 분해한 문서. 소재·연출·회차 구성·댓글 반응·순위 추이까지 |
| **직접 만들어 본 경험** | 웹툰이 아니어도 됨. 뉴스레터, 유튜브, 인스타툰, 팀 프로젝트, 교내 매거진 — **반응 데이터(조회수·구독·댓글)** 가 붙은 것 |
| **자사 서비스 뜯어보기** | 네이버웹툰 / 시리즈 앱을 실제로 쓰면서 이용 습관 기록 → 장단점 → **개선 기획안 1개**. 자소서 4번 문항과 인턴 과제에 그대로 쓰임 |
| **3키워드 압축 훈련** | 좋아하는 콘텐츠를 3개 키워드로 정리하는 연습. 자소서 1번 문항이자 면접 대응력의 핵심 |

### B. 있으면 확실히 갈리는 것

| 필요한 것 | 구체적으로 |
|---|---|
| **글로벌 감각** | 영문 WEBTOON, 일본 LINE망가, 미국 콘텐츠 앱을 실제로 써보고 국내와 뭐가 다른지. 자소서 5번 문항이 이걸 직접 물음 |
| **산업/비즈니스 이해** | 노블코믹스(웹소설→웹툰), IP 2차 사업(영상화·굿즈), 쿠키 유료화 모델, MAU·유료전환율 같은 지표 언어 |
| **작가와 일하는 감각** | PD 업무의 절반은 작가 섭외·일정·피드백 관리. 팀 프로젝트에서 **창작자와 부딪히며 결과물을 낸 경험**이 강력한 소재 |
| **일관성 있는 서사** | 전공·경험·지원동기가 하나의 이미지로 수렴하는가. 합격자가 직접 꼽은 차별화 포인트 |

### C. 굳이 안 해도 되는 것
- 토익·자격증·학점 끌어올리기 → 후기상 평가 요소로 언급되지 않음
- 웹툰을 그릴 줄 아는 능력 → PD 직군에는 요구되지 않음 (기획·분석·커뮤니케이션 직무)

## 7. 재학생 기준 실행 플랜

**~1개월차 — 재료 만들기**
- 작품 리뷰 5~6편 작성 (인기작 2 / 비인기작 2 / 신작 2). 편당 A4 1~2장
- 네이버웹툰·시리즈 앱 2주간 이용 로그 기록 (언제, 왜 열었고, 왜 껐는가)

**~2~3개월차 — 결과물 만들기**
- 웹소설 1편 골라 **웹툰화 기획서** 작성 (타깃·연출 포인트·경쟁작·예상 반응)
- 앱 **개선 기획안 1개** 작성 (문제 정의 → 근거 → 해결안 → 성공 지표)
- 위 3종을 하나의 포트폴리오로 묶기. **가장 자신 있는 1개**를 정해 5분 발표 버전까지 준비 (PT 면접 대비)

**~4~6개월차 — 경험 쌓기**
- 콘텐츠 관련 인턴 / 서포터즈 / 학회 활동 중 최소 1개
- 웹툰·스토리 공모전 참여 (본인이 창작자가 아니어도 기획·각색 부문 존재)
- 개인 채널(브런치·뉴스레터 등)에 웹툰 분석 연재 → **꾸준함 + 반응 데이터**가 동시에 남음

**지원 시점**
- 자소서 7개 문항을 **하나의 일관된 캐릭터**로 정렬
- 면접은 "취준생 답변" 아니라 **"내가 그 팀 PD라면"** 관점으로 리허설
- 예상 질문: "이 작품이 왜 안 됐다고 보나?", "네이버웹툰에서 지금 가장 문제라고 보는 건?", "작가와 의견이 갈리면?"
